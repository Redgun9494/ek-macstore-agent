# Dossier des images

Place ici les photos correspondant à chaque publication, avec **exactement** le nom de fichier indiqué dans `calendar.json` (champ `image_filename`).

Exemple : pour le post `w1-mon`, le fichier attendu est `w1-mon-education-neuf-vs-quasi-neuf.jpg`.

Formats acceptés : `.jpg` ou `.png`, idéalement en format carré (1:1) ou portrait (4:5), au moins 1080x1080 px.

⚠ Une publication Instagram est automatiquement **ignorée** (mais celle sur Facebook passe quand même) si l'image correspondante n'est pas présente ici au moment de l'exécution.

Pense à ajouter les photos (`git add images/... && git commit && git push`) **avant** la date prévue de chaque publication.
